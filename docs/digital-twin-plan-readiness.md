# 数字分身计划准备度与运行记录

在「组织 → 数字员工 → 目标 → 工作计划」中展开计划行，查看员工、目标、计划状态、计划内容完整性、匹配启用场景和已有运行记录。

检查依据仅为当前已加载数据，不增加 API 请求或授权规则。准备度不代表可执行授权或实时资源检查，缺失或过期数据标记为「未确认」。申请及执行时仍需服务端重新校验资源、权限和审批。

运行记录按组织、计划、岗位、Agent 及可用快照过滤，按创建时间倒序，超过五条分页。计划版本标签为当前、其他或未知版本；不相等时不推断新旧，因为当前加载数据可能已过期。运行成功不代表交付验收、目标完成或正式知识发布。

本轮没有聊天智能规划、自主采集、定时安排、技能进化或 AKB 发布。

## 验证

`planReadiness.test.tsx` 覆盖局部观察、对象隔离、记录排序、低于/高于当前版本、无记录状态。原工作区定向测试曾通过；重建代码仍须重新验证，不能继承原验证结论。全量测试受先前遥测审查阻塞，本轮不重试。
