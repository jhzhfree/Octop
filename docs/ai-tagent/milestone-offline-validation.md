# R1–R5 离线里程碑组合验证

## 可重复运行

在 Octop 仓库、已安装锁文件依赖的开发环境执行：

```sh
uv run --frozen pytest -q tests/integration/test_ai_tagent_milestone_offline.py
```

测试新建临时 SQLite 数据库，运行完整迁移，构造纯合成组织、两名用户、岗位、智能体、数字员工、知识源引用、目标与计划。不会接触开发或生产数据库。测试阶段阻断 socket 连接、DNS 查询及 UDP 发送，不启动真实模型、调度器或连接器。此 socket 阻断不是操作系统级网络隔离；测试不调用子进程。

## 实际验证的服务组合

1. 映射草稿写入与读取，快照当前，但 `retrieval_enabled=false`，外部用户 ACL 未验证。
2. 计划本地准备度检查，外部 ACL、预算、运行审批仍为 unknown，`execution_authorized=false`。
3. 真实场景运行申请生成待审批记录，真实服务拒绝申请人自审批。
4. **显式模拟边界**：测试直接通过仓储写入另一用户的模拟审批与 queued→succeeded；这不是实际审批执行通路或 cron 派发验证。
5. 成功运行只进入待人工验收统计；证据为服务端异步测试桩返回的合成文字，不是模型或 AKB 输出。
6. 真实验收服务拒绝自验收、跨组织访问和陈旧证据哈希；另一用户的显式测试决定分别覆盖 accepted 与 changes_requested，重复相同决定幂等。
7. 真实组织进展聚合保持执行与交付分离，单位为 run。验收不会自动完成目标、计划或启用知识检索，审计不存证据正文。

## 交付证据与限制

本文件对应独立测试为 2 个参数化用例。应以当次命令输出为准，不把历史结果当当前结果。此验证证明 SQLite 本地服务的数据组合与安全边界，不等同于端到端 UI 验收、PostgreSQL 验证、真实人类审批、生产安全认证，亦不证明 AKB/LiteLLM/new-api 或任何模型、外部知识库联通。

正式上线前仍需独立验证真实身份与委托 ACL、连接器权限、模型预算、调度派发、证据存储与读取、PostgreSQL 迁移及回归、浏览器完整操作路径。不得因本测试通过而自动授权或启用外部能力。
