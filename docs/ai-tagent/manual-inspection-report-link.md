# 企业晨检：人工关联报告快照与数字员工验收

## 本轮交付与边界

本轮增加一个**人工显式共享**步骤：运行申请人将自己已有的巡检汇总报告草稿，关联到同一自有 Agent 的成功数字员工运行。报告内容固定为不可变快照，获授权独立验收人可以在原交付摘要中同时查看模型执行结果和这份人工附加报告，并对组合证据进行验收。

这不是将两套工作流自动合并。报告仍由 `enterprise_assistant` 生成，数字员工仍由 `scene_run` 审批和调度。关联不证明报告由该次场景执行生成，也不证明报告内容已经满足目标；选择的报告可能是历史草稿，用户必须检查报告中的来源运行编号和采集时间以及人工修改内容。本轮不新增实时性承诺，不把原有最长七天来源时效当作当天采集。

关联**不会**发送企业微信、批准报告外发、再次运行模型、完成目标或替代独立验收。报告草稿 `awaiting_approval` 指的是原报告外发流程，不是场景验收状态。原报告的后续编辑不改变已经共享的快照；共享不能撤销或替换，错误关联需要新建场景运行。对于尚未关联报告的运行，原验收流程继续可用，不强制要求报告。

## 使用流程

1. 在企业助手中生成纯巡检汇总草稿；检查来源、采集时间及报告内容。现有报告配置仍需要企业微信连接，但本步骤不调用发送或批准接口。
2. 从数字员工就绪计划申请场景，由另一人批准，等待执行成功。
3. 申请人在组织页对应成功运行卡中打开“关联巡检报告”，输入本人报告运行 ID。预览只读取本人草稿，不产生共享。
4. 确认提示后，系统固定预览的版本和内容哈希，将其共享给该运行当前获授权的独立验收人。
5. 验收人在原交付摘要中看到执行摘要及 `[owner_shared_report_snapshot ...]` 标记后的固定报告内容。验收哈希覆盖两部分，并固定附件哈希。
6. 组织进度仍按场景运行与人工验收分别计算；不会据此自动完成目标或回写知识库。

关闭界面不取消已经提交的请求。请求结果不确定时不要自动重试；重新打开先读取既有附件。每个运行仅允许一次附件创建，重复提交返回 409，客户端可读取已有快照确认状态。

## API

- `GET /api/organizations/{org}/scene-runs/{run}/report-attachment/preview?report_run_id=...`
- `POST /api/organizations/{org}/scene-runs/{run}/report-attachment`
- `GET /api/organizations/{org}/scene-runs/{run}/report-attachment`

POST 必须提供 `report_run_id`、`expected_report_version`、`expected_content_hash` 以及 `share_with_reviewer: true`。请求不允许传入任意报告正文。所有返回设置 `Cache-Control: no-store`。预览/API 响应只返回固定文档或标识，不返回连接凭据、上游原始错误或报告连接配置。

读取范围：当前有效的申请人（仍具组织访问权），或当前有效的独立验收人（与原验收规则一致：批准者且是组织 owner/manager，或非申请人的平台管理员）。普通同组织管理者不能因为知道运行编号而读取附件。

创建还要求本人拥有启用的 Agent、当前具有任务权限及启用的巡检/报告模块、报告 owner 为本人、报告和场景 Agent 一致、报告为待外发审批草稿且来源均为巡检、场景执行成功且未验收。

固定共享后，历史附件的读取授权由场景权限决定，不再由原企业助手任务权限或原报告当前版本决定。这是主动共享快照，不是对私有报告实时链接的隐式访问。

## 一致性与迁移

迁移 035 为 SQLite 和 PostgreSQL 增加附件表及场景运行上的 `report_attachment_sha256`。旧无附件验收的快照哈希保持不变。PostgreSQL DDL 已与 SQLite 对齐，但未在真实 PostgreSQL 实例验证。

附件写入与审计记录在同一事务；用户、组织成员、场景运行按与验收相同顺序锁定。验收与附件共同锁场景行，先验收则不能附加，先附加则旧验收快照被拒绝。源报告版本/内容哈希及内容在事务中复核，用户禁用、成员移除、任务权限、模块开关和 Agent 启用/归属也在写入事务复核。SQLite 测试包含真正的双线程竞争；PostgreSQL 使用 `FOR UPDATE`，尚未实测多实例竞争。

报告正文仅存储在新附件表，不写入审计日志。审计只记录关联 ID、版本和哈希。附件不是秘密保险库：拥有数据库管理权限的人能访问正文。

新增隔离场景使用实际 SQLite、报告服务、采集适配器、场景申请/独立审批、Cron、Gateway、转录投影、附件服务和人工验收。只替换模型输出及 HTTP 数据传输，不直接写入执行成功或验收结果；测试禁止网络，并在 HTTP 替身中拒绝企业微信目的地。

样例来源为健康、异常磁盘 95%、超时。真实报告生成后仍为 `awaiting_approval`；关联和场景验收不改变其外发状态。测试包括源改稿后固定共享快照保持、预览后改稿拒绝、跨组织/非验收管理者拒绝、撤权事务检查、验收和关联并发、HTTP 完整字段契约与显式共享必填、35 迁移及旧哈希兼容。

前端组件、页面和 API 契约定向测试与构建由同轮验证执行。尚未验证真实浏览器端到端、真实模型/连接器、实际服务器、PostgreSQL、周期调度、知识写入或全量工程门禁。不能据此宣称整体企业产品已可用。
