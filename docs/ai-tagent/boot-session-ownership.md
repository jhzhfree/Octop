# 启动认证检查的会话归属

2026-11-16，开发基线 `f0bf28a03862c0c7a38623b0ddce3ef6f1be5438`。

## 问题与行为

公共请求封装的 401/503 保护不覆盖调用者自己的副作用。AuthGuard 启动时的
`/setup/status` 成功响应仍可能清理后续登录，旧 `/auth/me` 的成功或失败也可能
设置旧用户、修改语言或导航到登录页。认证模块还会根据成功的 setup 响应改写
全局初始化锁。

现在启动检查捕获本标签的登录代次及令牌，在每个异步阶段结束（含错误和语言
加载后）核验归属。失去归属时丢弃结果，保持业务页面未挂载，串行启动一次当前
会话的重新验证。没有自动重放写操作，也没有增加定时轮询。认证模块仅允许仍
属于发起会话的 setup 结果修改全局初始化锁；结果本身仍交给调用者处理。探测请求仅在同一会话内合并，旧请求结束不会清除
新会话的在途请求登记。

保留正常初始化导航、失效登录导航、离线重试和已登录后的应用内导航行为。
同标签使用相同令牌重新登录可通过代次区分；其他标签写入不同令牌可通过存储
比较检测。服务端授权仍是最终权限边界。

## 本阶段验证

- 定向前端回归：10 文件、99 项通过，含新增 6 项启动竞态测试和 3 项 setup
  标记及并发探测竞态测试。使用合成令牌、受控 Promise 与 jsdom，没有连接真实服务。
- 初次新增测试 6 项失败，原因是 auth 模块替身遗漏真实 `validAccessState`；
  改为保留真实模块导出后，定向及完整上述回归通过。随后类型检查发现 Promise
  自引用的初始化检查错误 TS2454，改用独有快照对象归属比较，并重新执行门禁。
- `UV_CACHE_DIR=/tmp/octop-uv-cache UV_OFFLINE=1 make lint-all typecheck-all`
  和 `npm run build` 最终均通过；mypy 663 个源文件，ESLint 69 warnings /
  0 errors，构建保留既有体积与依赖提示。全量 `make all` 含后端 pytest，
  本轮不运行，以避免受限遥测测试。未修改后端，也未重跑后端 pytest。

## 边界与未完成项

这不是跨标签原子 CAS，不覆盖跨标签令牌 ABA 或所有页面调用者；Login/Setup
等其他消费者的完整生命周期需要独立审查。已经开始的语言资源加载无法撤销，
但它完成后不会凭旧会话挂载业务页面，下一轮会应用当前账号语言。持续切换令牌
可能持续触发串行重验，不保证无感启动。测试不是实际多浏览器验收。

未实现服务端强制 idle/absolute 时限、完整恢复激活、ACL 映射及工作区/数据库
一致性回滚；在线与原地恢复继续关闭。Mattermost/模型/AKB 真实联调和生产部署
仍未验证，不能据此宣称达到 1.0。

本环境只读版本探测：Docker 客户端和服务端 29.9.2 可达，bubblewrap 0.12.0
已安装；未启动容器、未重试此前受限 bubblewrap 执行，不据版本证明隔离能力。
