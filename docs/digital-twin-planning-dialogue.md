# 数字分身对话规划（P1B 首步）

> 本文件与对应实现是在云工作区替换后依据执行记录重新编写的版本，不是原文件找回。恢复验收应以本次测试为准。

## 本轮实现

入口：组织 → 数字员工 → 已激活目标 → 对话规划。要求当前用户为组织 owner/manager（或管理员），且员工和目标处于 active 状态。

1. 用户明确发送需求，将当前职责、目标及成功标准与本面板内的对话发送给任命 Agent 的**显式默认模型**。
2. 模型可提出澄清问题（draft 为 null），也可返回可编辑的计划草案。
3. 点击“使用草案”仅填入现有计划编辑器。只有在编辑器中明确保存才创建计划，之后仍走既有准备、场景审批和执行前校验。

不运行 Agent 工具、不访问网址、不检索知识、不设置周期任务、不写入 AKB、不更改授权；模型回复和提案未经事实验证。“模型提出计划”不意味着资源已可用、计划已批准或任务完成。

## API 与数据

`POST /api/organizations/{organization_id}/digital-workers/{worker_id}/goals/{goal_id}/planning-dialogue`

请求：`worker_version` 和 `messages`，以及可选的 `previous_draft`（同响应草案的严格结构）。此前草案作为不可信上下文参与修订，不能代表已保存的计划或授权。messages 必须从 user 开始严格交替、以 user 结束，最多 12 条（最多 6 次用户发送），每条最多 4000 字。拒绝 system/tool 角色、额外字段和空白输入。客户端提供的 assistant 历史同样是不可信数据，而非已验证的模型历史或授权证明。

响应：`reply`、`draft`（可空）、`model_ref`。草案只能包含 title、approach、steps，每一步只能包含 action、expected_output。拒绝额外 status/permissions/tool 等字段、空白字段、超长或非 JSON 返回。

没有新数据库表或状态；上下文只在面板内维护。关闭清空且防止晚返回覆盖新面板。服务端请求超时 45 秒，生成时通过现有 LangChain 模型绑定传入 `max_tokens` 上限 4096（若 Agent 配置更低则沿用更低值）；不支持该参数的供应商请求会失败，不自动去掉限制重试。这不是岗位预算或总费用限额，也不能保证上游实现正确执行。关闭前端或超时不保证已发出的上游请求停止，也不保证不计费。

## 权限与模型边界

服务端在调用前核验组织管理权限、员工/目标所属关系、版本及激活状态、Agent 任命、启用及所有权/共享访问。返回前再次核验，目标改变或权限被撤销则不返回草案。

仅使用该 Agent 显式 `default_model`；不调用可能回退首个全局模型的 `pick_default_model_ref`，客户端不能指定其他模型。工厂和数据库的模型/供应商启用状态都要符合要求。无模型或运行时不可用会明确拒绝，不自动启用 Agent 或替换凭据。

本接口复用现有模型配置，不代表已实现岗位级独立预算、虚拟 Key 或费用台账。真实模型调用可能收费。代码不新增原始对话日志或数据库保存；上游模型服务和现有部署的追踪设置可能另有留存策略，须由部署方核验。不要在面板中输入凭据或未获授权外发的信息。

## 调用保护

在资源和模型检查通过后、模型请求前使用共享的进程内限流实例：每用户同时 1 次、滚动一分钟受理 6 次；每进程同时 4 次、滚动一分钟 60 次。超限返回 429 及 Retry-After，不排队、不自动重试。已受理的失败、超时及取消仍计入频率，退出时释放本地并发槽。

此处不是跨进程预算：重启会清空计数，多副本各自计数。上游生成未必随本地取消终止，不能将本地并发数当作供应商侧并发。详见 [调用保护说明](digital-twin-planning-limits.md)。

## 验证及限制

后端假模型测试覆盖角色和消息边界、跨组织/目标隔离、非管理者拒绝、Agent 可访问与任命、版本冲突、默认模型缺失和禁用、异常/超时不泄露详情、非法输出拒绝、运行中撤权或目标变更、API 结构校验及不保存计划。

恢复后新增接口级 429 / Retry-After、服务实例共享配额、取消释放以及授权拒绝不占模型受理额度的测试。前端测试覆盖发送及重复点击、六轮上限、关闭后晚返回、错误、前稿修订上下文和明确采用草案。父页接入与显式保存流程由恢复任务单独重新验证。

没有用真实供应商密钥执行验证。本轮不解决长期对话存储、模型输出事实验证、独立配额结算、可靠周期执行和端到端生产验收。此前全量测试的遥测安全阻塞仍未解除，本轮只运行定向检查，不宣称全量通过。
