# 数字分身：引导规划第一阶段

## 入口与范围

进入组织管理的数字员工区域，选择已有员工，再选择一个处于 `active` 状态的阶段目标。具有组织管理权限的人员可以在工作计划卡片点击 **引导规划**。

此入口复用现有员工、目标、计划和场景运行体系，不增加第二套任务数据库，不改变后端权限。

## 操作流程

1. 确认显示的目标与已有验收标准。
2. 填写候选素材渠道、期望交付物、验收岗位/人员，以及可选的执行节奏。
3. 点击“生成模板并进入编辑”。系统在浏览器内按固定模板整理五个步骤：范围与授权核查、只读采集、证据整合、交付草案、人工验收和改进建议。
4. 在原有计划编辑器逐项修改，明确资源边界、步骤、输出后，手动保存草案。
5. 仍通过现有计划就绪、场景选择及审批运行流程实施。输入验收人名称不会赋予该人权限。

关闭引导窗不会写入数据库，重新打开时清空未提交答案。切换组织、员工或目标会销毁该上下文的引导状态。

## 明确不包含

- 不是对话式或 LLM 自动规划，没有模型调用。
- 不验证网址、连接器或知识库是否可访问，不建立连接，也不扩大权限。
- 执行节奏是备注，不创建定时任务。
- 不自动采集、运行工具、安装技能或发布知识。
- 知识沉淀和技能改进仅写入“待审核建议”的步骤说明；既有记忆候选功能也不等同正式知识发布。
